这半年我折腾了些什么

2026-07-17By 兮
学习 笔记

写在前面

上半年咻一下就没了。我给自己定了个小规矩：少刷点推和转发，省下来的时间拿去写点代码、做点项目、把乱七八糟的笔记理一理。回头一看还真干了些东西，就记在这儿。

Rust：折腾了半年，写了个小工具

年初开始正经学 Rust。选它不是因为网上吹的什么「最受欢迎语言」，纯粹是它那个所有权和借用检查器，逼着你老老实实想内存到底归谁管。一开始被折磨得够呛，但确实学到东西。

大概是这么学过来的：

  • 《The Rust Programming Language》前 15 章精读
  • Rustlings 全部练习做完
  • 用 Clap 写了个 Markdown 转 HTML 的 CLI
  • 用 Axum 写了个最小化的 REST API

拿 Clap 搭的那个小工具，核心大概就这点：

use clap::Parser;

/// 一个简单的 Markdown 转 HTML 工具
#[derive(Parser)]
#[command(name = "md2html")]
#[command(version = "0.1.0")]
struct Cli {
    /// 输入 Markdown 文件路径
    input: String,

    /// 输出 HTML 文件路径
    #[arg(short = 'o', long = "output", default_value = "output.html")]
    output: String,
}

fn main() {
    let cli = Cli::parse();
    println!("转换 {} -> {}", cli.input, cli.output);
}

说真的，最大的收获不是语法。学完 Rust 之后再看别的代码，脑子里会自己蹦出几个问题：这数据归谁？能活多久？会不会打架？ 光这个习惯就值回票价了。

分布式那点事，补了下理论

花了一个半月，啃了两块：

  • Raft：跟着 MIT 6.824 的 Lab 2 把核心逻辑敲了一遍。选主、复制日志、快照，跑通之后对「一致性」这三个字总算有点手感了。
  • CAP：书上说得死，实际干活儿哪有那么绝对，多半是「这点一致性让一让，换个可用」。弄明白怎么取舍，比背定义管用多了。

Agent 框架，挨个试了试

这半年也在 Agent 框架里折腾了一阵，LangChain、CrewAI、AutoGen 都跑了一遍。说句大实话：这玩意儿现在还早，很多吹「自主决策」的，扒开代码一看，就是一堆排好队的状态机。

不过也真想明白了一件事：所谓的 Agent，核心就是这个圈，看一眼、想一下、动手、再看看结果。框架换来换去，这个套路估计短时间内变不了。

关于怎么学，想明白一点

这半年最有用的一条：与其贪多，不如钻透。我以前老爱「刷」，刷完一门课、刷完一本书，就觉得学会了。后来发现是自欺欺人。现在宁可在一个问题上耗几周，耗到能用大白话讲给别人听，才算真懂。

下半年打算接着啃 Rust，再把手头那些 Agent 的零散试验凑成一个真能跑的东西。焦虑没用，动手最实在。
