2026 上半年学习总结：在 AI 浪潮中保持清醒

2026-07-17 学习
学习笔记

写在前面

2026 年上半年一下子就过完了。这半年我故意少刷了一些推和文章，把省下来的时间拿去做点实在的事——写代码、做项目、整理笔记。下面就是这半年的回顾。

Rust：从入门到能写 CLI 工具

年初开始认真学 Rust。选它倒不是因为什么「最受喜爱的语言」，纯粹是它的所有权系统和借用检查器逼着你去想内存到底该怎么管。

学习路径大概是：

  • 《The Rust Programming Language》前 15 章精读
  • Rustlings 全部练习做完
  • 用 Clap 写了个 Markdown 转 HTML 的 CLI
  • 用 Axum 写了个最小化的 REST API

用 Clap 搭 CLI 工具大概长这样：

use clap::Parser;

/// 一个简单的 Markdown 转 HTML 工具
#[derive(Parser)]
#[command(name = "md2html")]
#[command(version = "0.1.0")]
struct Cli {
    /// 输入 Markdown 文件路径
    input: String,

    /// 输出 HTML 文件路径
    #[arg(short = 'o', long = "output", default_value = "output.html")]
    output: String,
}

fn main() {
    let cli = Cli::parse();
    println!("转换 {} -> {}", cli.input, cli.output);
}

说起来最大的收获其实不是语法本身。是学完 Rust 之后，看任何语言的代码脑子里都会冒出这几个问题——数据所有权是谁的？生命周期多久？会不会有数据竞争？ 这个习惯值回票价了。

分布式系统理论补课

花了一个半月啃了两个主题：

  • Raft 共识算法：跟着 MIT 6.824 的 Lab 2 实现了 Raft 核心逻辑。Leader Election、Log Replication、Snapshot 跑了一圈下来，对一致性问题算是有了点实操层面的感觉。
  • CAP 定理的工程实践：理论上 CAP 不可兼得，但工程里往往是「牺牲一点点 C 换 A，或者反过来」。搞懂这个权衡比把定理背下来有用得多。

AI Agent 框架调研

上半年也花了不少时间折腾 AI Agent 框架——LangChain、CrewAI、AutoGen 都跑了一遍。说实话，现在的 Agent 框架还非常早期，很多号称「自主决策」的东西，看代码其实就是精心编排的状态机。

不过确实搞明白了一件事：Agent 的核心抽象就是 感知 → 规划 → 执行 → 反馈 这个循环。框架可以换着花样来，但这个基本模式大概率不会过时。

方法论的反思

这半年最大的心得就四个字：深度 > 广度。我以前特别喜欢「刷」——刷完一门课、刷完一本书，就觉得自己学会了。后来发现那是错觉。现在我更愿意在一个问题上多待几周，直到能用大白话给别人讲清楚才算过。

下半年打算在 Rust 上继续深入，然后把手头 AI Agent 的实践落地成一个能跑的项目。与其焦虑不如动手。
