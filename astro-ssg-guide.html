Astro SSG 入门指南：从零构建高性能静态博客

2026-07-12 日常
AstroSSG前端

什么是 Static Site Generation

静态站点生成（SSG）的思路挺简单：构建的时候把所有页面预渲染成 HTML，部署直接扔静态文件上去就行了。没有服务器在跑，没有数据库要查，CDN 可以直接缓存全部内容。所以加载飞快，安全也好做。

不过传统 SSG 有个挺头疼的问题：每加一点交互功能，就得引入一堆 JavaScript。比如你想加个评论区或者搜索框，往往得把整页搞成 SPA，这就跟 SSG 的理念拧巴了。

Astro 用 Islands Architecture（群岛架构） 来解决这个问题。

Islands Architecture 详解

Astro 把页面拆成两块：

  • 静态海洋：页面主体内容（文章、导航、页脚），构建时直接渲染成 HTML，客户端零 JS。
  • 交互岛屿：需要交互的部分（评论区、主题切换按钮、搜索框），各自独立加载自己的 JS。

所以你的博客文章页可能只有评论区那 3KB 脚本，文章正文就是纯 HTML。体感上就是秒开。

// 示例：在 Astro 页面中引入交互式组件
---
// 顶部 frontmatter（服务端执行，不会发送到客户端）
import CommentSection from '../components/CommentSection';
import ThemeToggle from '../components/ThemeToggle.astro';
---
<article>
  <h1>{frontmatter.title}</h1>
  <!-- 纯静态内容 -->
  <Content />
</article>

<!-- 交互式岛屿：只在需要时才加载 JS -->
<CommentSection client:load />
<ThemeToggle client:idle />

Content Collections：类型安全的 Markdown

Content Collections 是我最喜欢 Astro 的地方。用 Zod schema 定义 frontmatter 结构之后，编辑器里能自动补全，构建时元数据错了直接报——再也不会出现文章上线了才发现日期格式不对这种事了。

import { getCollection } from 'astro:content';

// 获取所有博客文章，自动按日期排序
const posts = await getCollection('blog', ({ data }) => {
  return !data.draft;
});

// 按分类筛选
const aiPosts = posts.filter(
  post => post.data.category === 'AI'
);

路由与动态页面

Astro 的文件路由很直观。src/pages/blog/[slug].astro 自动匹配 /blog/hello-world/ 这种路径：

---
// src/pages/blog/[slug].astro
import { getCollection } from 'astro:content';

export async function getStaticPaths() {
  const posts = await getCollection('blog');
  return posts.map(post => ({
    params: { slug: post.slug },
    props: { post },
  }));
}

const { post } = Astro.props;
const { Content } = await post.render();
---
<BlogLayout frontmatter={post.data}>
  <Content />
</BlogLayout>

性能优化建议

  • 图片优化：用 Astro 内置的 <Image /> 组件自动生成 WebP/AVIF 格式
  • Font Optimization：通过 @fontsource 本地化字体，省掉 Google Fonts 的额外请求
  • Prefetch：用 <link rel="prefetch"> 预加载可能的下一页
  • View Transitions：Astro 3.0+ 内置页面过渡动画，体验接近 SPA

部署到 Cloudflare Pages

Astro 部署到 Cloudflare Pages 非常省心。连上 GitHub 仓库，构建命令填 npm run build，输出目录设 dist，每次推送自动部署。免费套餐有无限带宽和全球 CDN，个人博客绰绰有余。

Astro 的生态还在成长。如果你下一个静态站点还没选定框架，可以试试看——至少搭博客这件事它会让你很舒服。
