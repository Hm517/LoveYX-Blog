我为什么又搭了个博客

2026-07-10By 兮
博客 Astro

为啥非要自己搭个博客

现在公众号、知乎、Notion、Medium 都挺好用，在上面写东西确实方便。但我还是想自己搭一个，有些东西，平台给不了。

头一个就是东西是自己的。在别人地盘上写，人家哪天改个规矩、说停就停，你的文章说没就没。自己的博客不一样：域名是你的，GitHub 上那个仓库也是你的，没有哪个算法替你决定这篇该不该被看见。

再一个，我写字老想塞代码、塞公式，偶尔还想整个能点的图表。大部分平台的代码高亮就那么回事，Mermaid、LaTeX 基本别指望。自己搭的话，想怎么渲染就怎么渲染。

为啥挑了 Astro

生成器一抓一把，Hugo、Gatsby、Next.js、Hexo 都有人用。挑来挑去选了 Astro，主要是这几点戳到我：

  • Islands Architecture：大部分就是纯 HTML，哪儿要交互哪儿才下 JS。默认零 JS，打开就秒开。
  • 多个框架混着用：一个项目里 React、Vue、Svelte 各玩各的，互相不打架。
  • Content Collections：拿 Zod 定义好文章的结构，写着写着编辑器就给你补全，格式错了当场报错，挺省心。

随手举个例，定义一篇文章长啥样，就这么几行：

// src/content/config.ts
import { defineCollection, z } from 'astro:content';

const blogCollection = defineCollection({
  type: 'content',
  schema: z.object({
    title: z.string(),
    date: z.date(),
    category: z.string(),
    tags: z.array(z.string()),
    description: z.string(),
    cover: z.string().optional(),
  }),
});

export const collections = { blog: blogCollection };

这博客打算写点啥

主题嘛，技术、AI、生活，再加一堆乱七八糟的念头。我不想只写技术，摄影、读书、去哪儿玩了，都往上丢。博客就该是完整的自己，干嘛非把自己框在一个话题里。

接下来打算干的：

  • 把标签和分类导航弄顺
  • 接上 Giscus，讨论都挪回 GitHub
  • 加个 RSS，不靠任何平台推
  • 性能再抠抠，Lighthouse 往 95 以上冲

先写到这

搭博客本身就挺好玩的。每一行代码、每一处留白、挑的每个字体，都是自己的痕迹。希望这个小园子慢慢长起来，路过的朋友常来坐坐。
